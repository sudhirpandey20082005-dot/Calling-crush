# HangOut

2-person chat + audio call + video call (WhatsApp style). Single static page, no backend.
Uses the free PeerJS cloud server to connect two browsers.

## Deploy on Render (Static Site)
1. Push this folder to a GitHub repo (index.html must be in the repo root).
2. Render dashboard -> New -> Static Site -> connect the repo.
3. Build command: (leave empty)   Publish directory: .
4. Deploy. You get an https:// link.

## Use
Open your Render link -> "Start new chat" -> tap the link icon to copy the invite
-> send it to your friend -> they open it and tap "Join chat".
